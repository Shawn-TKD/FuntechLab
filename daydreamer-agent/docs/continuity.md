# 片段连续性要求

## 验收目标

多个片段拼接后，应表现为同一段连续经历。场景、物件、视点、动作及时间前后承接，不能只有故事大意相连而画面在接缝处发生跳变。

这是一项验收目标，不代表当前生成模型可以保证每次自动达成。此前的《风铃校准小巷》是三次独立文生视频后拼接，不能视为已经通过本项验收。

## 当前生效策略

用户已确认加入 `wan3.0-video-prime`。新任务默认 `frame_chain`：首段使用 `wan3.0-video-prime`，后段使用前段实际剪辑末帧作为唯一首帧，严格顺序生成。原任务与预览保留不变；可用 `--continuity single_take` 选择3–15秒单次文生视频。

首帧传递加强画面承接，但模型仍可能自行生成跳切、运动速度或物件变化；当前不做媒体内容检查，因此不能宣称实际画面已经验证为完全连贯。

每镜附加 `continuity.start` 与 `continuity.end`，独立于四项 prompt，包含：

- camera_position：眼睛所在位置与高度。
- view_direction：视线方向。
- camera_motion：视点方向、速度、动作阶段。
- layout：场景与主要物件的空间关系。
- object_states：人物、手、持有物、物件状态与进行中的变化。
- lighting：光源方向、亮度与色彩。

文本合同检查要求前段 end 和后段 start 逐字段相同；这仅检查计划，不替代实际画面验证。

Qwen 创作阶段可将后段 start 输出为 `{"from_shot": "前镜编号"}`，程序严格从紧邻前镜 end 展开，避免近义改写引入差异。响应归档同时保留原文和展开结果。已写成完整六字段却存在冲突的状态不会被静默覆盖，仍须修订。

模型若把 `start_state` / `end_state` 也写成同一份结构化状态，程序仅在内容与 continuity 完全对应时无损转成文字；不一致时继续报错。提示词模板1.2只发送一份已重复的完整状态，避免冗余描述占用提示词长度。

## 已实现的多片段续接流程

1. 第一段使用文生视频。
2. 将第一段实际用于剪辑的最后一帧导出为图片。不能取最终被剪掉的源片尾帧。
3. 下一段使用 `wan3.0-video-prime`，以上一段导出的图片作为唯一首帧；提示词明确延续的动作方向、速度、视线和物件状态，不重演已经发生的动作。
4. 严格顺序生成；持久化前段镜头版本、尾帧及校验值。前段变更使依赖它的后续片段失效，不混用旧片段。
5. 剪辑保持一致的尺寸、时间基准和帧率，避免叠化、黑场或重复停顿掩盖不连续。
6. 首帧约束不等于视频续写：它不能直接携带上一段的运动速度和完整时序信息。若要正式认定完全连贯，需要人工验收或单独启用接缝检查；未经确认不启用媒体内容检查。

每次尝试保存原始 `clip.mp4`、归一化的 `prepared.mp4`、`tail.png`，以及前段的尝试编号、剪辑片段和末帧 SHA-256。Base64 只在发送接口请求时构建，不写入归档。首帧续接请求设置 ratio=adaptive；内部仍保留目标画幅用于技术校验。首段和后段都使用 wan3.0-video-prime，区别为是否传入 first_frame。

`retry-shot` 为失败镜头准备新尝试；`regenerate-shot` 可重做成功或失败镜头。续接模式下，两者同时使依赖它的后续片段失效，保留旧尝试文件，清除当前成片和预览索引。尚在运行或提交不明的任务不能被覆盖。上述命令不立即调用模型，下一次 `render` 才提交新尝试。

自动超时重提是单独规则：单次提交5分钟仍排队/运行，复查后最多自动重提一次；只在后续镜头尚未生成时执行，前段成功片段复用。后段必须绑定新尝试的版本及末帧。计时与次数跨命令恢复保留，不适用于未知提交或查询网络失败；旧任务仍可能继续计费。参数与恢复方式见README。

技术测试覆盖逐段依赖、重复提交防护、变更后拒绝混用，以及实际末帧与拼接边界的像素一致性。测试不会判定模型生成的运动是否自然连贯。

## 官方接口依据

- [万相3.0接口](https://help.aliyun.com/zh/model-studio/wan3-video-generation-api-reference)：wan3.0-video-prime统一支持文生视频及首帧图生视频，首帧可使用Base64，续接使用ratio=adaptive。

模型支持2–30秒；本次仅替换视频模型，应用的单镜制作策略仍为3–15秒，避免同时改变现有故事时长规则。提示词最多20000字符；原生音轨与自动提示词改写关闭。历史产物与模型快照不修改，旧模型请求不能继续提交，重做时须导入故事新建任务。
