# 根据幻想情节选择视觉风格

在主题和脚本完成后使用本文件。历史视觉方案不是候选来源；历史世界的叙事事实仍须遵守。

## 非写实边界

所有候选与最终方案必须明确非写实。禁止写实、微写实、半写实、照片级真实、真人实拍感，以及将这些表现与动画混合；写成 realistic、semi-realistic、photorealistic、live-action 等同义标签也不能作为正向风格要求。

先选择适合情节的非写实媒介，再用造型、材质和光线落实：例如手绘线条与色块、剪纸层次、卡通化黏土形体、非写实三维动画的夸张比例和简化表面。只有“梦幻”“奇幻”“电影感”不足以证明非写实；三维、定格或微缩模型也必须明确风格化，避免成为真实模型摄影。

第一人称双手、身体局部、其他人物与环境使用同一非写实表现，不追求真实皮肤毛孔、实拍纹理或照片级材质。开场、结尾和转场同样适用；不能先呈现写实生活再变成动画。若输入偏好带有写实要求，保留情绪或构图意图，转成符合本边界的方案，并在 assumptions 说明调整。

## 选择依据

根据连续行动需要选择表现手段：追逐需要读清目标、道路与转弯方向，交战需要读清掩体、攻击方向与作用结果，近距离操作需要看清手与物件的接触。先保证目标、行动和空间可理解，再结合情绪与节奏选择风格；不新增事后核查流程。

非写实不等于抽象化。二维、剪纸和三维都可以使用清晰轮廓、体积、遮挡、接触阴影和尺度关系表达空间，不默认禁止透视、阴影或体积。不得把每个物件化为不可辨认的几何碎片，也不要把纸片滑动等制作手法当作道路能被任意替换的世界规则。

输出一套协调的方案：

| 项目 | 决定内容 |
| --- | --- |
| 画面媒介 | 手绘、二维动画、绘本、剪纸、风格化黏土或非写实三维动画等；说明明确区别于实拍的造型与表面特征 |
| 造型与空间 | 形体语言、尺度、纵深、必要辨识标志 |
| 色彩 | 主辅色关系、视觉焦点与随情节变化的方式 |
| 材质 | 关键物件和环境的表面与运动特征 |
| 光线 | 光源、软硬、明暗关系及叙事作用 |
| 运动表现 | 物体运动的重量、速度、弹性与节奏；视点运动仍受第一人称约束 |
| 选择理由 | 具体说明这些选择如何让核心奇想、行动和情绪更清楚 |
| 稳定约束与过渡 | 全片保持的特征；如确有风格变化，注明触发情节和过渡镜头 |

不以一串画风标签代替可执行描述，不默认固定艺术家、媒介或色板。不将“新颖”简单等同于风格更多、更亮或更复杂。

## 协调示例

- 踩水影响掌心尺度的海洋：可选择非写实黏土动画，以圆润夸张的鞋尖作为尺度参照，用简化小船与层叠蓝色色块表现水体，使参与行为易懂；不因此强制所有水景使用该风格。
- 洗衣机洗出天气：可使用卡通化纤维手工动画，让织物与云雾共享简化的柔软纤维造型，颜色从滚筒冷光过渡到衣物中的晚霞；双手和家电同样风格化，所有变化仍围绕“洗出天气”。
- 机械空间的精密连锁反应：可使用二维描边动画、夸张齿轮与平涂明暗引导因果关系；压迫感不是所有机械情节的默认情绪。

背景音乐配合行动节奏，音效对应可见的物理或幻想变化。将机位、声音和美术都用于同一主题，不为增强效果额外创造无关事件。
