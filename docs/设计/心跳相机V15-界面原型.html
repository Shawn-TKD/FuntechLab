04改动依据 · V14 → V15 每条改动都对应一个具体的可用性问题，而非主观审美偏好。
维度V14 现状V15 方案设计依据
信息架构单页 13 个区块纵向平铺，需滚动 3 屏才能走完全流程4 Tab 按任务分区（控制台/素材/设置/诊断）移动端单屏宜承载 5±2 个信息组；按任务而非控件类型分区，符合心智模型
心率反馈42sp 文本置于页顶，向下滚动后完全不可见环形仪表 + appbar 常驻状态胶囊关键运行时数据须常驻可见，不能与滚动位置耦合
阈值理解两个裸 EditText，迟滞机制只存在于 12sp 说明文字里区间带可视化 + 双滑块联动 + 边界自动钳制把「需要记住的规则」转为「可以直接看见的事实」，降低认知负荷
上传流程①②③ 编号按钮 + 200 字长文案 + 两个 180dp 内嵌滚动区三步 stepper + 单选列表 + 底部固定操作条流程状态外显（当前在第几步、选中了什么、要传多大）；消除嵌套滚动的手势冲突
停止 / 断开单个「停止/断开」按钮一次做三件事：停模拟心率 + 停扫描 + 断开相机拆成两个独立动作：停止心率触发（模拟/手表/扫描 + 结束本次录制）与断开相机（仅相机）两件事代价不对称 —— 重启心率源是秒级操作，重连相机要切系统 WiFi + 等 SDK 握手。合并会强迫用户为「只想停心率」付出重连相机的代价
操作视觉权重「停止/断开」「模拟心率」与常规按钮同列同权重，全部是实底按钮按代价分级：主流程用实底（accent），停止/断开用弱底 + 语义描边（warn / danger）实底按钮的视觉权重最高，应留给「推进任务」的动作；破坏性动作若同为实底，会诱导误触
触控目标系统默认 Button，高度未显式保证统一 ≥ 48dp，主操作 56dp，间距 ≥ 8dpWCAG 2.5.8 Target Size (Minimum) + Material 48dp 建议
主题硬编码浅色（#FAFAFA）Token 化，明暗双主题，深色为默认相机类 App 户外强光取景与夜间作业均需可读；深色同时降低 OLED 功耗
可访问性次级文字 #757575 on #FAFAFA ≈ 4.6:1，无状态语义全部文本 ≥ 4.5:1；状态用「图标 + 文字 + 颜色」三重编码色盲用户无法仅凭颜色区分状态（WCAG 1.4.1 不能只靠颜色传达信息）
交付说明 · 本原型为静态高保真稿，用于评审视觉与交互方向；点击右上角可切换明/暗主题。 落地所需的 Android 资源值（colors.xml / dimens.xml / styles.xml）见同目录《心跳相机V15-UI设计规范.md》。
字体为系统字体栈（国内 Android 设备渲染为 HarmonyOS Sans / 思源黑体），行高统一 1.5，数字启用 tabular-nums。
